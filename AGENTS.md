# AGENTS.md - Physicall Project Conventions

## Project Overview

Physicall is a Rust + WASM + WebGPU physics simulation project. The core physics engine is written in Rust, compiled to WASM, and rendered in the browser using WebGPU.

## Directory Structure

```
physicall/
├── Cargo.toml                    # Workspace root
├── crates/
│   └── physicall-core/           # Main Rust WASM library
│       ├── Cargo.toml
│       ├── pkg/                  # Generated by wasm-pack (gitignored)
│       └── src/
│           └── lib.rs
├── web/                          # TypeScript/Vite frontend
│   ├── package.json
│   ├── vite.config.ts
│   ├── tsconfig.json
│   ├── index.html
│   └── src/
│       ├── main.ts
│       └── style.css
└── docs/
    ├── plans/
    └── research/
```

## Build Commands

### WASM Build (from project root)

```bash
# Debug build
cd crates/physicall-core && wasm-pack build --target web --out-dir pkg

# Release build
cd crates/physicall-core && wasm-pack build --target web --out-dir pkg --release

# With WebGPU unstable APIs
RUSTFLAGS=--cfg=web_sys_unstable_apis wasm-pack build --target web --out-dir pkg
```

### Frontend (from web/ directory)

```bash
# Install dependencies
cd web && npm install

# Development server (builds WASM first)
cd web && npm run dev

# Production build
cd web && npm run build
```

### Full Verification

Run these commands to verify the entire project builds correctly:

```bash
# 1. Build WASM
cd crates/physicall-core && wasm-pack build --target web --out-dir pkg

# 2. Install frontend dependencies (if needed)
cd web && npm install

# 3. Build frontend
cd web && npm run build
```

## Code Style

### Rust
- Use `cargo fmt` before committing
- Use `cargo clippy` to catch common issues
- All public functions should have doc comments

### TypeScript
- Use TypeScript strict mode
- Prefer `const` over `let`
- Use async/await for asynchronous operations

## Key Dependencies

### Rust (from Cargo.toml)
- `wasm-bindgen = "0.2.100"` - WASM/JS interop
- `console_error_panic_hook = "0.1.7"` - Better panic messages in browser
- `web-sys` - Web API bindings

### TypeScript (from web/package.json)
- `vite = "^6.0.0"` - Build tool
- `vite-plugin-wasm = "^3.4.1"` - WASM support
- `vite-plugin-top-level-await = "^1.4.4"` - Top-level await support

## Common Tasks

### Adding a new exported function

1. Add the function in `crates/physicall-core/src/lib.rs`:
   ```rust
   #[wasm_bindgen]
   pub fn my_function() { ... }
   ```

2. Rebuild WASM:
   ```bash
   cd crates/physicall-core && wasm-pack build --target web --out-dir pkg
   ```

3. Import in TypeScript:
   ```typescript
   import init, { my_function } from '../../crates/physicall-core/pkg/physicall_core';
   ```

### Debugging WASM

- Use `console_log!` macro for logging from Rust
- Panics will appear in browser console with stack traces (thanks to `console_error_panic_hook`)
- Use browser DevTools → Sources → wasm to debug WASM
