# Plan: E1.3 Instanced Rendering with Compute-to-Render Buffer Sharing

## Overview

Replace the existing 200 demo points with a GPU-driven particle system capable of rendering 10,000+ particles at 60fps. Particles will simulate N-body gravitational attraction entirely on the GPU using compute shaders, with shared buffers between compute and render passes (no CPU-GPU transfer per frame).

The implementation uses double-buffered particle storage (ping-pong pattern) where the compute shader reads from one buffer and writes to the other, while the render pass reads from the buffer that was just written.

## Architecture Decisions

- **Double-buffering**: Two particle buffers alternate each frame to avoid read-write conflicts. Compute reads buffer[N], writes buffer[N+1]; render reads buffer[N+1].
- **Keep explicit vertex attributes**: Continue using `VertexStepMode::Instance` with per-instance attributes rather than storage buffer indexing in vertex shader. Cleaner and already working.
- **32-byte particle struct**: Maintain current alignment (position: vec3, size: f32, velocity: vec3, _padding: f32). Cache-friendly, matches WGSL alignment rules.
- **Workgroup size 256**: Standard compute dispatch size for particle simulations.
- **N-body O(N²) initially**: Simple all-pairs gravitational attraction. Can optimize with spatial partitioning later if needed.
- **Minimal JS API**: No new exports. Simulation runs automatically in render loop.

### Compute Bind Group Layout

```rust
// Binding 0: Read buffer (storage, read-only)
// Binding 1: Write buffer (storage, read-write)
// Binding 2: Simulation params (uniform)
```

Two bind groups needed (for ping-pong):
- `bind_group_0`: read from buffer[0], write to buffer[1]
- `bind_group_1`: read from buffer[1], write to buffer[0]

### Compute Shader (Pass-Through)

`shaders/particle_compute.wgsl`:

```wgsl
struct Particle { ... }
struct SimParams { delta_time: f32, ... }

@group(0) @binding(0) var<storage, read> particles_in: array<Particle>;
@group(0) @binding(1) var<storage, read_write> particles_out: array<Particle>;
@group(0) @binding(2) var<uniform> params: SimParams;

@compute @workgroup_size(256)
fn main(@builtin(global_invocation_id) id: vec3u) {
    let idx = id.x;
    if (idx >= arrayLength(&particles_in)) { return; }

    // Pass-through: copy input to output unchanged
    particles_out[idx] = particles_in[idx];
}
```

### Render Loop Modification

```rust
fn render(&mut self) {
    // 1. Update sim params (delta_time)

    // 2. Compute pass
    let read_idx = self.frame_index % 2;
    let write_idx = (self.frame_index + 1) % 2;
    {
        let mut compute_pass = encoder.begin_compute_pass(&Default::default());
        compute_pass.set_pipeline(&self.compute_pipeline);
        compute_pass.set_bind_group(0, &self.compute_bind_groups[read_idx], &[]);
        compute_pass.dispatch_workgroups((self.particle_count + 255) / 256, 1, 1);
    }
    // Implicit memory barrier here

    // 3. Render pass - read from write_idx (just written by compute)
    render_pass.set_vertex_buffer(1, self.particle_buffers[write_idx].slice(..));
    render_pass.draw_indexed(0..6, 0, 0..self.particle_count);

    // 4. Increment frame index
    self.frame_index += 1;
}
```

## Phase 2: N-Body Physics Compute Shader

### Goal

Implement gravitational N-body simulation in the compute shader. Each particle attracts every other particle based on inverse-square law. Particles should orbit, cluster, and interact dynamically.

### Files to Modify

- `shaders/particle_compute.wgsl` - Add N-body physics
- `crates/physicall-core/src/lib.rs` - Add time tracking for delta_time

### SimParams Uniform

```rust
#[repr(C)]
#[derive(Copy, Clone, Debug, bytemuck::Pod, bytemuck::Zeroable)]
struct SimParams {
    delta_time: f32,
    gravity_strength: f32,  // G constant
    damping: f32,           // Velocity damping (0.99 typical)
    particle_count: u32,
}
```

### Compute Shader Physics

```wgsl
@compute @workgroup_size(256)
fn main(@builtin(global_invocation_id) id: vec3u) {
    let idx = id.x;
    if (idx >= params.particle_count) { return; }

    var particle = particles_in[idx];
    var acceleration = vec3f(0.0);

    // N-body: sum gravitational forces from all other particles
    for (var i = 0u; i < params.particle_count; i++) {
        if (i == idx) { continue; }

        let other = particles_in[i];
        let diff = other.position - particle.position;
        let dist_sq = dot(diff, diff) + 0.01; // Softening to avoid singularity
        let dist = sqrt(dist_sq);
        let force_mag = params.gravity_strength / dist_sq;
        acceleration += normalize(diff) * force_mag;
    }

    // Integrate velocity and position (semi-implicit Euler)
    particle.velocity += acceleration * params.delta_time;
    particle.velocity *= params.damping;
    particle.position += particle.velocity * params.delta_time;

    particles_out[idx] = particle;
}
```
