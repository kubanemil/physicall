# Plan: E0.1 Project Setup

## Overview

Set up the foundational development environment for Physicall - a Rust + WASM + WebGPU physics simulation project. This creates a working build pipeline where `wasm-pack build` compiles Rust to WASM, `npm run dev` serves a Vite app at localhost, and `console_log!` from Rust appears in browser devtools.

## Architecture Decisions

- **WASM target**: `--target web` for ES modules (cleaner Vite integration than `--target bundler`)
- **Vite plugins**: `vite-plugin-wasm` + `vite-plugin-top-level-await` (recommended by research)
- **Logging**: Manual `console_log!` macro via wasm-bindgen (simpler than console_log crate)
- **Project structure**: Nested `web/` directory matching PROJECT_PLAN.md for future scalability
- **Versions**: wgpu 28.0, wasm-bindgen 0.2.100, Vite 6.0, TypeScript 5.7

## Prerequisites

- [x] Rust toolchain installed (`rustup`)
- [x] wasm-pack installed (`cargo install wasm-pack`)
- [x] Node.js 18+ and npm installed

**`physicall-core` crate** - WASM library exposing initialization and logging

Exports:
- `init()` - Called on WASM load, sets panic hook, logs "WASM initialized"

Key macros:

## Phase 2: Vite Frontend

### Goal

Create the TypeScript/Vite frontend that loads and initializes the WASM module.

### Files to Create

- `web/package.json` - NPM package with scripts and dependencies
- `web/vite.config.ts` - Vite configuration with WASM plugins
- `web/tsconfig.json` - TypeScript configuration
- `web/index.html` - Entry HTML with canvas element
- `web/src/main.ts` - Entry point that loads WASM
- `web/src/style.css` - Basic styles for canvas

### Module Design

**`web/package.json`** - NPM scripts and dependencies

Key scripts:
- `wasm:build` - Runs wasm-pack build
- `dev` - Builds WASM then starts Vite dev server
- `build` - Production build (WASM release + Vite build)

Dependencies:
```json
{
  "devDependencies": {
    "vite": "^6.0.0",
    "vite-plugin-wasm": "^3.4.1",
    "vite-plugin-top-level-await": "^1.4.4",
    "typescript": "^5.7.0"
  }
}
```

**`web/vite.config.ts`** - Vite configuration

```typescript
// Plugins: wasm(), topLevelAwait()
// optimizeDeps.exclude: ['physicall-core']
```

**`web/src/main.ts`** - WASM loader

