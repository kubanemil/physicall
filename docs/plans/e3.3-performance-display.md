# Plan: E3.3 Performance Display

## Overview

Add a real-time performance stats overlay showing FPS, frame time (ms), and particle count. The stats panel is positioned top-right, styled consistently with the existing controls panel, toggleable via `Ctrl+Y`, and updates every 500ms. The particle count display is moved from the controls panel to this new stats panel. All changes are TypeScript/HTML/CSS only — no WASM or shader modifications needed.

## Architecture Decisions

- **FPS in TypeScript**: Use `requestAnimationFrame` timestamp parameter for frame-to-frame timing, no WASM involvement
- **Smoothing**: Exponential moving average (EMA) with alpha=0.1 for stable, readable FPS/frame-time values
- **Display throttle**: Internal tracking every frame, DOM updates every 500ms
- **Position**: Top-right corner, `position: fixed`, mirrors controls panel styling
- **Toggle**: `Ctrl+Y` keyboard shortcut, visible by default
- **Particle count moved**: Removed from `#controls` info-group, displayed only in stats panel
- **Non-interactive**: `pointer-events: none` so clicks pass through to canvas

## Prerequisites

- [ ] E3.1 UI controls implemented (controls panel exists)

## Phase 2: TypeScript — FPS Tracking & Display Updates

### Goal

Wire up FPS calculation, frame time tracking, and throttled DOM updates.

### Files to Modify

- `web/src/main.ts` — Rework render loop to accept rAF timestamp, add FPS/frame-time EMA tracking, throttle display updates to 500ms, remove old particle count update code

### Design

**State variables** (module-level):

- `lastFrameTimestamp: number` — previous rAF timestamp (ms)
- `smoothedFps: number` — EMA-smoothed FPS
- `smoothedFrameTime: number` — EMA-smoothed frame time (ms)
- `lastDisplayUpdate: number` — timestamp of last DOM update
- `statsVisible: boolean` — toggle state (default `true`)

**Render loop changes:**

1. Change `renderLoop()` signature to `renderLoop(timestamp: DOMHighResTimeStamp)`
2. Compute `frameTime = timestamp - lastFrameTimestamp` (skip first frame)
3. Compute instantaneous `fps = 1000 / frameTime`
4. Apply EMA: `smoothedFps = smoothedFps * 0.9 + fps * 0.1` (same for frame time)
5. Every 500ms (`timestamp - lastDisplayUpdate >= 500`): update DOM text for FPS (rounded integer), frame time (1 decimal), and particle count
6. Remove old `frameCount` / `particleCountDisplay` / every-10-frames logic

**DOM element references** (grabbed once at setup):

- `fpsValue = getElementById('fps-value')`
- `frametimeValue = getElementById('frametime-value')`
- `statsParticleCount = getElementById('stats-particle-count')`
- `statsPanel = getElementById('stats')`

**Initial rAF call:** `requestAnimationFrame(renderLoop)` — rAF naturally passes timestamp.

## Phase 3: Toggle Shortcut

### Goal

Add `Ctrl+Y` keyboard shortcut to show/hide the stats panel.

### Files to Modify

- `web/src/main.ts` — Extend existing `keydown` listener to handle `Ctrl+Y`

### Design

In the existing `document.addEventListener('keydown', ...)` handler:

- Check `e.ctrlKey && (e.key === 'y' || e.key === 'Y')`
- Toggle `statsVisible` flag
- Toggle `hidden` class on `#stats` element
- Call `e.preventDefault()` to avoid browser default for Ctrl+Y

Update help text in `web/index.html` to include `Ctrl+Y: Stats`.
