# Plan: E3.1 UI Controls

## Overview

Add a control panel to the Physicall WebGPU simulation that allows users to pause/resume the simulation, reset to initial state, and adjust parameters (gravity, time scale) via sliders. The implementation extends the existing WASM↔JS interop pattern with new exported functions and adds a semi-transparent overlay UI panel.

## Architecture Decisions

- **Pause implementation**: Skip compute dispatch when paused; continue camera updates and render pass so user can orbit while paused
- **Reset implementation**: Store initial particles in State during initialization; on reset, write them back to both ping-pong buffers
- **Parameter storage**: Add mutable fields to State struct; use them when constructing SimParams each frame
- **UI approach**: Plain HTML/CSS overlay panel (top-left), no framework; direct WASM function calls from event handlers
- **Paused indicator**: Simple "PAUSED" text overlay centered on canvas

## Prerequisites

- [x] Working M2 particle simulation (complete)
- [x] Existing WASM↔JS interop (complete)

## Phase 4: Frontend UI Panel

### Goal

Add HTML controls panel with buttons and sliders wired to WASM functions.

### Files to Modify

- `web/index.html` - Add controls panel HTML structure
- `web/src/style.css` - Add panel and control styling
- `web/src/main.ts` - Import new WASM functions, add event handlers, manage UI state

### Module Design

**HTML structure** (`web/index.html`):
```html
<div id="controls">
  <button id="pause-btn">Pause</button>
  <button id="reset-btn">Reset</button>
  <div class="slider-group">
    <label>Gravity: <span id="gravity-value">0.3</span></label>
    <input type="range" id="gravity-slider" min="-2" max="2" step="0.1" value="0.3">
  </div>
  <div class="slider-group">
    <label>Speed: <span id="speed-value">1.0</span></label>
    <input type="range" id="speed-slider" min="0" max="3" step="0.1" value="1">
  </div>
</div>
<div id="paused-overlay" class="hidden">PAUSED</div>
```

**CSS** (`web/src/style.css`):
- `#controls`: Fixed position top-left, semi-transparent dark background, padding, border-radius
- `#controls button`: Styled buttons with hover states
- `.slider-group`: Flex layout for label + slider
- `#paused-overlay`: Centered text overlay, large font, semi-transparent

**TypeScript** (`web/src/main.ts`):

New imports:
```typescript
import init, {
  init_webgpu, render, resize, reset_camera,
  set_paused, reset_simulation, set_gravity, set_time_scale, get_paused
} from '../../crates/physicall-core/pkg/physicall_core';
```

UI state:
```typescript
let isPaused = false;
```

Event handlers:
- `pause-btn` click: Toggle `isPaused`, call `set_paused()`, update button text, toggle overlay
- `reset-btn` click: Call `reset_simulation()`
- `gravity-slider` input: Call `set_gravity()`, update value display
- `speed-slider` input: Call `set_time_scale()`, update value display

### Integration

- Controls overlay on top of canvas (z-index)
- Canvas remains full viewport, controls don't resize it
- Slider updates are immediate (next frame)
