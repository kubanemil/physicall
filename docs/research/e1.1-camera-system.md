# Research: E1.1 Camera System

## Research Question

How to implement an interactive orbit camera for the Physicall WebGPU simulation? What are the patterns for camera matrices, mouse input handling, and integration with the existing wgpu renderer?

## Summary

Implementing an orbit camera in wgpu/WASM requires three components: (1) camera math using spherical coordinates and view/projection matrices, (2) mouse event handling via web-sys closures, and (3) uniform buffer integration to pass camera data to shaders.

**Key findings:**
1. **Use `glam`** for linear algebra - it's the wgpu standard, has native WebGPU-compatible projection functions, and supports bytemuck out of the box
2. **Orbit camera** uses spherical coordinates (radius, azimuth, polar) converted to Cartesian for the eye position
3. **Mouse events** require web-sys features and closure management with `Rc<RefCell<T>>` for shared state
4. **Uniform buffers** need `#[repr(C)]` structs with bytemuck derives for GPU upload
5. **Shader changes** require a bind group for camera uniforms and multiplication by view_proj matrix

## Detailed Findings

### 1. Linear Algebra: Use glam

**Recommendation: glam** (not cgmath or nalgebra)

| Crate | Status | WebGPU Depth Range | WASM Support |
|-------|--------|-------------------|--------------|
| glam | Active, wgpu standard | Native [0,1] | Excellent + SIMD128 |
| cgmath | Unmaintained since 2021 | Requires correction matrix | Works |
| nalgebra | Active, for physics | Requires correction matrix | Full |

**Cargo.toml addition:**
```toml
glam = { version = "0.29", features = ["bytemuck"] }
```

**Why glam:**
- wgpu officially switched from cgmath to glam in examples
- `Mat4::perspective_rh()` outputs [0,1] depth range (WebGPU native)
- `Mat4::look_at_rh()` for view matrix
- Built-in bytemuck support via feature flag
- Smallest binary size for WASM

### 2. Orbit Camera Math

An orbit camera positions the viewer on a sphere around a target point using spherical coordinates:

- **radius**: Distance from target (zoom level)
- **azimuth** (yaw/theta): Horizontal rotation (radians)
- **polar** (pitch/phi): Vertical rotation (radians), clamped to avoid gimbal lock

**Spherical to Cartesian conversion:**
```rust
fn eye_position(radius: f32, azimuth: f32, polar: f32, target: Vec3) -> Vec3 {
    let cos_polar = polar.cos();
    Vec3::new(
        target.x + radius * cos_polar * azimuth.cos(),
        target.y + radius * polar.sin(),
        target.z + radius * cos_polar * azimuth.sin(),
    )
}
```

**Camera struct pattern:**
```rust
use glam::{Mat4, Vec3};
use std::f32::consts::FRAC_PI_2;

const SAFE_FRAC_PI_2: f32 = FRAC_PI_2 - 0.0001;

pub struct OrbitCamera {
    pub target: Vec3,      // Point to orbit around
    pub radius: f32,       // Distance (zoom)
    pub azimuth: f32,      // Horizontal angle
    pub polar: f32,        // Vertical angle (clamped)
    pub min_radius: f32,
    pub max_radius: f32,
}

impl OrbitCamera {
    pub fn eye(&self) -> Vec3 {
        let cos_polar = self.polar.cos();
        Vec3::new(
            self.target.x + self.radius * cos_polar * self.azimuth.cos(),
            self.target.y + self.radius * self.polar.sin(),
            self.target.z + self.radius * cos_polar * self.azimuth.sin(),
        )
    }

    pub fn view_matrix(&self) -> Mat4 {
        Mat4::look_at_rh(self.eye(), self.target, Vec3::Y)
    }

    pub fn rotate_azimuth(&mut self, delta: f32) {
        self.azimuth += delta;
    }

    pub fn rotate_polar(&mut self, delta: f32) {
        self.polar = (self.polar + delta).clamp(-SAFE_FRAC_PI_2, SAFE_FRAC_PI_2);
    }

    pub fn zoom(&mut self, delta: f32) {
        self.radius = (self.radius - delta).clamp(self.min_radius, self.max_radius);
    }
}
```

**Projection (separate, only changes on resize):**
```rust
pub struct Projection {
    pub aspect: f32,
    pub fov_y: f32,
    pub z_near: f32,
    pub z_far: f32,
}

impl Projection {
    pub fn matrix(&self) -> Mat4 {
        // glam's perspective_rh uses [0,1] depth - correct for wgpu
        Mat4::perspective_rh(self.fov_y, self.aspect, self.z_near, self.z_far)
    }

    pub fn resize(&mut self, width: u32, height: u32) {
        self.aspect = width as f32 / height as f32;
    }
}
```

### 3. Mouse Event Handling in web-sys

**Required web-sys features:**
```toml
[dependencies.web-sys]
workspace = true
features = [
    # Existing features...
    "MouseEvent",
    "WheelEvent",
    "EventTarget",
    "AddEventListenerOptions",
]
```

**Key MouseEvent properties:**
- `offset_x()`, `offset_y()` - Position relative to canvas (most useful)
- `movement_x()`, `movement_y()` - Delta since last event (for drag)
- `button()` - Which button triggered event (0=left, 1=middle, 2=right)
- `buttons()` - Bitmask of pressed buttons (1=left, 2=right, 4=middle)

**Key WheelEvent properties:**
- `delta_y()` - Scroll amount (negative = scroll up)
- `delta_mode()` - Units (0=pixels, 1=lines, 2=pages)

**Closure pattern with shared state:**
```rust
use std::cell::RefCell;
use std::rc::Rc;
use wasm_bindgen::prelude::*;
use wasm_bindgen::JsCast;
use web_sys::{HtmlCanvasElement, MouseEvent, WheelEvent};

struct InputState {
    is_dragging: bool,
    last_x: i32,
    last_y: i32,
    rotate_delta: (f32, f32),
    zoom_delta: f32,
}

fn setup_mouse_events(
    canvas: &HtmlCanvasElement,
    state: Rc<RefCell<InputState>>,
) -> Result<(), JsValue> {
    // Mousedown
    {
        let state = state.clone();
        let closure = Closure::<dyn FnMut(_)>::new(move |event: MouseEvent| {
            if event.button() == 0 { // Left button
                let mut s = state.borrow_mut();
                s.is_dragging = true;
                s.last_x = event.client_x();
                s.last_y = event.client_y();
            }
        });
        canvas.add_event_listener_with_callback(
            "mousedown",
            closure.as_ref().unchecked_ref()
        )?;
        closure.forget(); // Keep closure alive
    }

    // Mousemove
    {
        let state = state.clone();
        let closure = Closure::<dyn FnMut(_)>::new(move |event: MouseEvent| {
            let mut s = state.borrow_mut();
            if s.is_dragging {
                let dx = event.client_x() - s.last_x;
                let dy = event.client_y() - s.last_y;
                s.rotate_delta.0 += dx as f32;
                s.rotate_delta.1 += dy as f32;
                s.last_x = event.client_x();
                s.last_y = event.client_y();
            }
        });
        canvas.add_event_listener_with_callback(
            "mousemove",
            closure.as_ref().unchecked_ref()
        )?;
        closure.forget();
    }

    // Mouseup (on window to catch releases outside canvas)
    {
        let state = state.clone();
        let window = web_sys::window().unwrap();
        let closure = Closure::<dyn FnMut(_)>::new(move |_: MouseEvent| {
            state.borrow_mut().is_dragging = false;
        });
        window.add_event_listener_with_callback(
            "mouseup",
            closure.as_ref().unchecked_ref()
        )?;
        closure.forget();
    }

    Ok(())
}

fn setup_wheel_event(
    canvas: &HtmlCanvasElement,
    state: Rc<RefCell<InputState>>,
) -> Result<(), JsValue> {
    let closure = Closure::<dyn FnMut(_)>::new(move |event: WheelEvent| {
        event.prevent_default(); // Prevent page scroll

        let delta = event.delta_y();
        let normalized = match event.delta_mode() {
            0 => delta / 100.0, // Pixels
            1 => delta / 3.0,   // Lines
            _ => delta / 100.0,
        };

        state.borrow_mut().zoom_delta += normalized as f32;
    });

    // Must use non-passive to call preventDefault
    let options = web_sys::AddEventListenerOptions::new();
    options.set_passive(false);

    canvas.add_event_listener_with_callback_and_add_event_listener_options(
        "wheel",
        closure.as_ref().unchecked_ref(),
        &options,
    )?;
    closure.forget();

    Ok(())
}
```

### 4. Uniform Buffer for Camera

**CameraUniform struct (GPU-compatible):**
```rust
use bytemuck::{Pod, Zeroable};

#[repr(C)]
#[derive(Debug, Copy, Clone, Pod, Zeroable)]
pub struct CameraUniform {
    view_proj: [[f32; 4]; 4],
}

impl CameraUniform {
    pub fn new() -> Self {
        Self {
            view_proj: glam::Mat4::IDENTITY.to_cols_array_2d(),
        }
    }

    pub fn update(&mut self, camera: &OrbitCamera, projection: &Projection) {
        let view = camera.view_matrix();
        let proj = projection.matrix();
        self.view_proj = (proj * view).to_cols_array_2d();
    }
}
```

**Buffer and bind group creation:**
```rust
// Create buffer
let camera_uniform = CameraUniform::new();
let camera_buffer = device.create_buffer_init(&wgpu::util::BufferInitDescriptor {
    label: Some("Camera Buffer"),
    contents: bytemuck::cast_slice(&[camera_uniform]),
    usage: wgpu::BufferUsages::UNIFORM | wgpu::BufferUsages::COPY_DST,
});

// Create bind group layout
let camera_bind_group_layout = device.create_bind_group_layout(
    &wgpu::BindGroupLayoutDescriptor {
        label: Some("Camera Bind Group Layout"),
        entries: &[wgpu::BindGroupLayoutEntry {
            binding: 0,
            visibility: wgpu::ShaderStages::VERTEX,
            ty: wgpu::BindingType::Buffer {
                ty: wgpu::BufferBindingType::Uniform,
                has_dynamic_offset: false,
                min_binding_size: None,
            },
            count: None,
        }],
    }
);

// Create bind group
let camera_bind_group = device.create_bind_group(&wgpu::BindGroupDescriptor {
    label: Some("Camera Bind Group"),
    layout: &camera_bind_group_layout,
    entries: &[wgpu::BindGroupEntry {
        binding: 0,
        resource: camera_buffer.as_entire_binding(),
    }],
});
```

**Update buffer per frame:**
```rust
camera_uniform.update(&camera, &projection);
queue.write_buffer(&camera_buffer, 0, bytemuck::cast_slice(&[camera_uniform]));
```

### 5. Shader Changes

**Updated WGSL shader:**
```wgsl
struct CameraUniform {
    view_proj: mat4x4<f32>,
};

@group(0) @binding(0)
var<uniform> camera: CameraUniform;

struct VertexInput {
    @location(0) position: vec3f,
    @location(1) color: vec3f,
}

struct VertexOutput {
    @builtin(position) clip_position: vec4f,
    @location(0) color: vec3f,
}

@vertex
fn vs_main(input: VertexInput) -> VertexOutput {
    var output: VertexOutput;
    // Transform by view-projection matrix
    output.clip_position = camera.view_proj * vec4f(input.position, 1.0);
    output.color = input.color;
    return output;
}

@fragment
fn fs_main(input: VertexOutput) -> @location(0) vec4f {
    return vec4f(input.color, 1.0);
}
```

### 6. Pipeline Layout Changes

The render pipeline needs to include the camera bind group layout:

```rust
let render_pipeline_layout = device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor {
    label: Some("Render Pipeline Layout"),
    bind_group_layouts: &[&camera_bind_group_layout],
    push_constant_ranges: &[],
});

let render_pipeline = device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
    label: Some("Render Pipeline"),
    layout: Some(&render_pipeline_layout), // Changed from None
    // ... rest unchanged
});
```

**In render pass:**
```rust
render_pass.set_bind_group(0, &camera_bind_group, &[]);
render_pass.set_pipeline(&render_pipeline);
render_pass.set_vertex_buffer(0, vertex_buffer.slice(..));
render_pass.draw(0..3, 0..1);
```

## Architecture Notes

### Component Organization

The camera system should be organized as:

```
crates/physicall-core/src/
├── lib.rs              # Main exports, State struct
├── camera.rs           # OrbitCamera, Projection, CameraUniform
└── input.rs            # Mouse event handling, InputState
```

Or initially, all in lib.rs with modules extracted later.

### Data Flow

```
Mouse Events (web-sys)
       ↓
  InputState (Rc<RefCell>)
       ↓
  OrbitCamera.rotate/zoom()
       ↓
  CameraUniform.update()
       ↓
  queue.write_buffer()
       ↓
  Shader receives view_proj
```

### State Management

The current design uses `thread_local!` with `RefCell<Option<State>>`. Camera and input state should integrate with this pattern:

```rust
struct State {
    // Existing fields...
    surface: wgpu::Surface<'static>,
    device: wgpu::Device,
    queue: wgpu::Queue,
    // ...

    // New camera fields
    camera: OrbitCamera,
    projection: Projection,
    camera_uniform: CameraUniform,
    camera_buffer: wgpu::Buffer,
    camera_bind_group: wgpu::BindGroup,
}
```

Input state needs to be accessible from closures, so it should be `Rc<RefCell<InputState>>` stored separately or passed to State methods.

## Open Questions

1. **Camera vs particle interaction (M3)**: The PR FAQ flagged this as NEEDS DECISION. Options:
   - Left-click always orbits, right-click for particles
   - Shift+drag for orbit, plain drag for particles
   - Mode toggle button

2. **Default camera position**: Suggested defaults:
   - target: `Vec3::ZERO` (origin)
   - radius: `5.0` (see the triangle clearly)
   - azimuth: `PI / 4` (45° horizontal)
   - polar: `PI / 6` (30° elevation)
   - fov_y: `45.0_f32.to_radians()`

3. **Sensitivity values**: Need testing, suggested starting points:
   - rotate_speed: `0.005` radians per pixel
   - zoom_speed: `0.1` units per scroll unit

4. **Y-axis inversion**: Most 3D software uses "natural" (drag up = look up). Can add option later in M3 UI.
